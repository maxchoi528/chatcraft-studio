1. Data Processing & Zero-Cloud Architecture

All conversation extraction, privacy redaction, Markdown formatting, OpenXML Microsoft Word (.docx) compilation, HTML theming, and code .zip packaging run strictly locally inside your browser using bundled scripts.

2. Local Browser Storage

We store only non-sensitive configuration preferences locally via chrome.storage.local: your UI language choice, custom redaction keywords, selected visual theme, and optional Pro activation metadata.

3. Minimal Permissions

  • storage: Saves your UI preferences and Pro activation state locally.
  • activeTab: Reads the current AI tab only when you trigger export or open Studio.
  • contextMenus: Lets you send selected text on any page to the formatting Studio.
  • api.gumroad.com: Contacted solely if you enter a Pro license key to verify purchase validity via Gumroad's official License Verify endpoint. Zero conversation text is ever included in that request.
